moyami · 내 리더 만들기

확장 소스로 만화와 소설을 읽는 나만의 웹 리더를 Vercel 무료 요금제에 만듭니다. 이 화면의 세 단계만 따라 하면 됩니다.

  • GitHub 계정
  • Vercel 계정 (GitHub로 가입 가능)
  • 약 5분

가입 키 만들기

내 리더에 처음 가입할 때 쓰는 비밀 키입니다. 이 브라우저 안에서만 만들어지고 어디에도 전송되지 않습니다.

키는 자동으로 저장되지 않습니다. 이 창을 닫기 전에 파일로 보관하거나 메모해 두세요. 2단계와 3단계에서 같은 키를 두 번 씁니다.

Vercel에 배포하기

Vercel 배포 시작 ↗

먼저 1단계에서 가입 키를 만들어 주세요.

새 창에서 이렇게 진행하세요

  1. GitHub로 로그인하고 저장소 이름을 정한 뒤 Create를 누릅니다. 이름은 자유롭게 정해도 됩니다.
  2. Upstash 저장 공간 연결 화면이 나오면 새로 만들고, 요금제는 Free를 고릅니다. 로그인 계정과 읽기 기록을 보관하는 작은 저장 공간입니다.
  3. 환경변수 입력 칸을 아래처럼 채우고 Deploy를 누릅니다.
  • BOOTSTRAP_KEY1단계에서 복사한 키를 붙여 넣기
  • SITE_NAME위에 적은 앱 이름이 자동으로 들어가 있어요

계정 연결과 외부 서비스 약관 동의는 직접 진행해야 합니다. 배포가 끝나면 Continue to Dashboard 또는 앱 미리보기를 눌러 내 앱 주소(이름.vercel.app)를 엽니다.

관리자로 가입하고 읽기 시작

  1. 내 앱 주소를 열면 관리자 계정 만들기 화면이 나옵니다.
  2. 1단계의 가입 키와 원하는 아이디·비밀번호(10자 이상)를 입력합니다. 다음부터는 아이디·비밀번호만 씁니다.
  3. 설정 → 확장 소스 → 저장소 → 저장소 추가에 사용할 Mangayomi JS 저장소 주소를 넣고, 소스를 고릅니다. 기본으로 들어 있는 저장소는 없습니다.

휴대폰에서는 브라우저 메뉴의 홈 화면에 추가로 앱처럼 쓸 수 있습니다. 다른 사람을 초대하려면 설정 → 계정 → 가입 키 발급을 쓰세요.

막혔을 때

“저장 공간 연결이 필요합니다”라고 나와요

앱은 만들어졌지만 계정과 읽기 기록을 보관할 곳이 아직 연결되지 않았다는 뜻입니다.

  1. Vercel 대시보드에서 내 moyami 프로젝트를 엽니다.
  2. Storage → Create Database에서 Upstash → Redis를 고르고, Free 요금제로 새 저장 공간을 만듭니다.
  3. Connect to Project에서 내 프로젝트를 고릅니다. 환경을 묻는다면 Production을 선택합니다.
  4. Deployments에서 가장 최근 배포의 ⋯ → Redeploy를 누릅니다.
  5. 끝나면 내 앱을 새로고침합니다. 가입 화면이 보이면 연결된 것입니다.

주소와 토큰은 연결할 때 Vercel이 자동으로 넣어 줍니다. 직접 복사할 필요가 없습니다.

“첫 가입 키가 설정되지 않았습니다”라고 나와요

배포할 때 BOOTSTRAP_KEY를 넣지 않았거나 32자보다 짧습니다.

  1. 이 화면 1단계에서 키를 만들고 보관합니다.
  2. Vercel 프로젝트의 Settings → Environment Variables에서 이름 BOOTSTRAP_KEY, 값에 키를 넣고 저장합니다.
  3. Deployments → ⋯ → Redeploy를 누른 뒤 앱을 새로고침합니다.
새 버전을 배포했는데 예전 화면이 계속 보여요

moyami는 설치형 앱(PWA)이라 화면 파일을 기기에 보관합니다. 새 버전은 이 앱의 탭과 창을 모두 닫았다가 다시 열 때 적용됩니다. 새로고침만으로는 바뀌지 않습니다.

  1. 이 앱을 연 브라우저 탭과 설치한 앱 창을 모두 닫습니다. 휴대폰은 최근 앱 목록에서도 밀어서 닫습니다.
  2. 다시 엽니다. 한 번에 안 바뀌면 한 번 더 닫았다 엽니다.

그래도 안 되면 사이트 데이터를 지웁니다. 이 기기에 남은 기록과 설정도 함께 지워지지만, 동기화된 읽기 기록은 다시 로그인하면 돌아옵니다.

  • PC Chrome·Edge: 앱을 열고 F12 → Application → Storage → Clear site data → 새로고침
  • Android Chrome: 설정 → 사이트 설정 → 모든 사이트 → 내 앱 주소 → 삭제
  • iPhone·iPad: 설정 → Safari → 고급 → 웹사이트 데이터 → 내 앱 주소 검색 → 삭제. 홈 화면 앱은 아이콘을 지우고 다시 추가합니다.
예전 접근 키 방식(moya-source-lite)에서 옮겨 왔어요

같은 Vercel 프로젝트에 moyami를 배포하면 접근 키 대신 계정 로그인으로 바뀝니다.

  1. Environment Variables에 BOOTSTRAP_KEY(1단계에서 생성)와 SITE_NAME을 추가합니다.
  2. 더 이상 쓰지 않는 APP_ACCESS_KEY는 지워도 됩니다. APP_SECRET은 moyami도 로그인 서명에 쓰므로 그대로 둡니다.
  3. 다시 배포한 뒤 위 “예전 화면이 계속 보여요” 방법으로 기기의 예전 화면을 정리합니다.
  4. 관리자 계정을 만들고 저장소를 다시 추가합니다. 예전 기록은 계정 없이 저장된 것이라 새 계정으로 옮겨지지 않습니다.
주소나 앱 이름을 바꾸고 싶어요

앱 이름은 SITE_NAME 환경변수를 바꾸고 다시 배포하면 됩니다. 개인 도메인은 Vercel 프로젝트의 Settings → Domains에서 연결합니다. 브라우저 연결 확장을 쓴다면 APP_URL=https://내-도메인을 추가해 다시 배포하고 확장을 다시 설치하세요.

키와 입력한 값은 이 페이지 밖으로 전송되지 않습니다. 자세한 설명은 moyami README를 참고하세요.
