내 브라우저로 연결

원본 사이트를 사용하는 기기에서 직접 불러옵니다. 개인 서버는 필요하지 않으며, 웹 리더 제공 서비스는 계속 사용합니다.

홈 화면에 설치

모야의 설정 → 화면 → 앱 설치 또는 브라우저의 홈 화면에 추가 메뉴를 이용하세요. 앱 화면과 최근 읽기를 저장하며 새 작품·회차를 불러올 때는 인터넷 연결이 필요합니다. 연결 확장은 앱 설치와 별개입니다. 앱 창에서 연결 확장을 찾지 못하면 확장이 켜진 브라우저의 일반 탭으로 열어 주세요.

설치 상태

현재 연결 확장은 개발 검증 단계입니다. 스토어 배포와 iPhone·iPad·Android 실제 기기 검증은 아직 완료되지 않았습니다.

  • iPhone·iPad: Safari용 확장 앱을 TestFlight 또는 App Store로 설치한 뒤 Safari 설정에서 켭니다. ZIP 파일만으로 설치할 수는 없습니다.
  • Android: Firefox용 서명된 확장이 필요합니다. Android Chrome용으로 제공하지 않습니다.
  • PC: 개발자는 Chromium의 확장 관리에서 개발자 모드를 켜고 제공된 패키지를 압축 해제해 로드할 수 있습니다.

개발·검증용 패키지

  • PC Chromium 압축 해제용
  • Firefox 서명 전 소스 패키지 — Android 일반 설치본은 아직 없습니다.
  • Safari 변환·서명용 패키지 — iPhone에서 ZIP을 직접 설치할 수 없습니다.

사용 순서

  1. 연결 확장을 설치하고 Moya 사이트에서 사용을 허용합니다.
  2. 리더의 ‘설정 → 원본 연결 설정’에서 ‘내 브라우저’를 선택합니다.
  3. 사이트 권한 안내가 나오면 확장 아이콘을 열고 해당 사이트를 허용합니다.
  4. 접근이 거부되면 확장에서 ‘사이트 열기’를 누릅니다. 원본에서 직접 인증하고 그 탭을 열어 둡니다.
  5. 리더로 돌아와 다시 시도합니다.

이 확장은 원본의 인증을 자동으로 해결하지 않습니다. 원본 자체가 기기에서 열리지 않으면 인터넷 연결이나 사이트 상태를 먼저 확인하세요. Safari 일반 탭에서 사용하며 홈 화면 웹앱과 비공개 모드는 검증하지 않았습니다.

원본 쿠키를 리더나 서버에 내보내지 않습니다. 확장 팝업에서 사이트 권한을 취소할 수 있습니다.
