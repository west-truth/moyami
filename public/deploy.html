moyami · 내 리더 만들기

확장 소스로 만화와 소설을 읽는 개인 웹 리더입니다. 아래에서 키를 준비한 뒤 Vercel 배포를 시작하세요.

1. 첫 가입 키 만들기

키는 이 브라우저에서 생성됩니다. 배포 환경변수와 첫 관리자 가입에 같은 키를 사용합니다.

키는 자동 저장하지 않습니다. 창을 닫기 전에 복사하거나 파일로 보관하세요.

2. Vercel에 배포

Vercel에서 GitHub 계정과 연결하고 원하는 저장소·프로젝트 이름을 정하세요. 계정과 읽기 기록을 보관할 온라인 저장 공간인 Upstash Redis를 연결합니다. 요금제는 Free(무료)를 선택하고, 환경변수 BOOTSTRAP_KEY에 위 키를 붙여 넣으세요.

Vercel 배포 시작 ↗

계정 연결 및 외부 서비스 약관 동의는 직접 진행해야 합니다. 표시 이름은 SITE_NAME 환경변수로, 접속 주소는 Vercel Domains에서 변경할 수 있습니다.

3. 가입하고 소스 추가

배포된 주소를 열어 보관한 키로 관리자 계정을 만드세요. 이후에는 아이디·비밀번호로 로그인합니다. 확장 저장소는 기본으로 등록되어 있지 않으니 직접 주소를 추가하세요.

다른 사람을 초대하려면 설정 → 계정 → 가입 키 발급을 사용하세요.

저장 공간 연결 안내가 나오나요?

앱에 계정과 읽기 기록을 보관할 곳이 아직 연결되지 않았다는 뜻입니다.

  1. Vercel 대시보드에서 내 moyami 프로젝트를 엽니다.
  2. Storage → Create Database에서 Upstash Redis를 선택합니다. 처음이라면 새 저장 공간을 만들고 Free 요금제를 선택하세요.
  3. Connect to Project에서 내 프로젝트를 선택합니다. 환경을 묻는다면 Production을 선택하세요.
  4. Deployments에서 최근 배포의 ⋯ → Redeploy를 누릅니다.
  5. 완료 후 내 앱 주소를 새로고침합니다. 가입 화면이 보이면 연결된 것입니다.

주소나 토큰은 연결 과정에서 자동으로 등록됩니다. 직접 복사해서 입력할 필요가 없습니다.

첫 가입 키가 없다는 안내라면 위에서 키를 만들고, 프로젝트의 Settings → Environment Variables에 이름 BOOTSTRAP_KEY와 키 값을 추가한 뒤 Redeploy 하세요.
