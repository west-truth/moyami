나만의 만화·소설 리더 만들기

moyami는 확장 소스로 만화와 소설을 읽는 개인용 웹 리더입니다. 아래 세 단계를 따라 하면 Vercel 무료 요금제에 내 리더가 만들어집니다.

  • GitHub 계정
  • Vercel 계정 (GitHub로 가입)
  • 약 5분

가입 키 만들기

내 리더에 처음 가입할 때 쓰는 비밀 키입니다. 이 브라우저 안에서만 만들어지고 어디에도 전송되지 않습니다.

키는 자동으로 저장되지 않으니 파일로 보관해 두세요. 2단계와 3단계에서 같은 키를 씁니다.

Vercel에 배포하기

Vercel 배포 시작 ↗

먼저 1단계에서 가입 키를 만들어 주세요.

새 창에서 할 일

  1. GitHub로 로그인하고, 저장소 이름을 정한 뒤 Create를 누릅니다.
  2. Upstash 저장 공간을 새로 만들고 요금제는 Free를 고릅니다. 계정과 읽기 기록을 보관하는 곳입니다. Free가 안 보이면 유료 요금제를 고르지 말고 새 창을 닫은 뒤, 아래 Free가 안 보일 때 방법으로 배포하세요.
  3. 환경변수를 아래처럼 채우고 Deploy를 누릅니다.
  • BOOTSTRAP_KEY1단계에서 복사한 키를 붙여 넣기
  • SITE_NAME위에 적은 앱 이름이 미리 들어가 있어요

계정 연결과 약관 동의는 직접 진행해야 합니다. 배포가 끝나면 앱 미리보기를 눌러 내 앱 주소(이름.vercel.app)를 엽니다.

가입하고 읽기 시작

  1. 내 앱 주소를 열면 관리자 계정 만들기 화면이 나옵니다.
  2. 1단계의 가입 키와 원하는 아이디·비밀번호(10자 이상)를 입력합니다. 다음부터는 아이디·비밀번호만 씁니다.
  3. 설정 → 확장 소스 → 저장소 → 저장소 추가에 쓸 Mangayomi JS 저장소 주소를 넣고 소스를 고릅니다.

휴대폰에서는 브라우저 메뉴의 홈 화면에 추가로 앱처럼 쓸 수 있습니다. 다른 사람은 설정 → 계정 → 가입 키 발급으로 초대합니다.

Free가 안 보일 때: Fork로 배포하기

이미 Upstash 저장 공간을 만든 적 있는 계정에서는 2단계 새 창에 Free 없이 유료 요금제만 보일 수 있습니다. 이때는 Upstash 콘솔에서 Free 저장 공간을 직접 만들고, 저장소를 Fork해서 배포합니다. 1단계의 가입 키와 2단계의 앱 이름은 그대로 씁니다.

Upstash에 무료 저장 공간 만들기

Upstash 콘솔 열기 ↗
  1. GitHub로 로그인하고 Create Database를 누릅니다.
  2. 이름은 자유롭게 정하고, Primary Region은 앱 서버(서울)와 가까운 곳을 고릅니다. 서울이 없으면 도쿄(Tokyo)를 고르세요.
  3. 요금제는 Free를 고르고 만듭니다. Pay as you go는 사용한 만큼 요금이 나오니 고르지 마세요.
  4. 만든 데이터베이스 화면의 REST API 항목에서 주소와 토큰을 복사해 아래에 붙여 넣습니다.

주소는 https://로 시작하는 REST 주소입니다. redis://나 rediss://로 시작하는 주소는 쓰지 않습니다. 붙여 넣은 값은 C단계에서 한꺼번에 복사하는 데만 쓰입니다.

GitHub에서 Fork하기

moyami Fork하기 ↗
  1. Owner가 내 계정인지 확인하고, 저장소 이름은 그대로 두거나 원하는 이름으로 바꿉니다.
  2. Copy the main branch only는 체크된 채로 두고 Create fork를 누릅니다.

Vercel에서 가져와 배포하기

Vercel 프로젝트 만들기 ↗

  1. Import Git Repository 목록에서 B단계에서 만든 저장소의 Import를 누릅니다. 목록에 없으면 Adjust GitHub App Permissions에서 그 저장소 접근을 허용합니다.
  2. Framework Preset과 Build and Output Settings는 건드리지 않습니다. 저장소의 설정 파일을 그대로 씁니다.
  3. Environment Variables를 펼치고 첫 Key 칸에 복사한 내용을 붙여 넣으면 네 줄이 한 번에 채워집니다. 안 되면 아래 표를 보고 하나씩 넣습니다.
  4. Deploy를 누르고, 끝나면 위 3단계대로 가입합니다.
  • BOOTSTRAP_KEY1단계에서 만든 가입 키
  • SITE_NAME2단계에 적은 앱 이름
  • UPSTASH_REDIS_REST_URLA단계의 REST 주소
  • UPSTASH_REDIS_REST_TOKENA단계의 REST 토큰

막혔을 때

“저장 공간 연결이 필요합니다”라고 나와요

계정과 읽기 기록을 보관할 Upstash Redis가 아직 연결되지 않은 상태입니다.

  1. Vercel 대시보드에서 내 moyami 프로젝트를 엽니다.
  2. Storage → Create Database에서 Upstash → Redis를 고르고 Free 요금제로 만듭니다.
  3. Connect to Project에서 내 프로젝트를, 환경은 Production을 고릅니다.
  4. Deployments에서 가장 최근 배포의 ⋯ → Redeploy를 누릅니다.
  5. 끝나면 앱을 새로고침합니다. 가입 화면이 보이면 완료입니다.

주소와 토큰은 Vercel이 자동으로 넣어 줍니다. Free가 안 보이면 A단계대로 Upstash 콘솔에서 Free 저장 공간을 만들고, Settings → Environment Variables에 UPSTASH_REDIS_REST_URL과 UPSTASH_REDIS_REST_TOKEN을 직접 넣은 뒤 다시 배포하세요.

Upstash 요금제에 Free가 안 보여요

이미 Upstash 저장 공간을 만든 적 있는 계정에서는 Vercel 화면에 Pay as you go나 Fixed 같은 유료 요금제만 보일 수 있습니다. Pay as you go는 Free의 무료 사용량이 따로 남지 않고 처음부터 사용량만큼 요금이 붙으니 고르지 마세요.

대신 Fork로 배포하기를 따라 Upstash 콘솔에서 Free 저장 공간을 직접 만들어 연결하세요.

“첫 가입 키가 설정되지 않았습니다”라고 나와요

배포할 때 BOOTSTRAP_KEY를 넣지 않았거나 32자보다 짧습니다.

  1. 이 페이지 1단계에서 키를 만들고 보관합니다.
  2. Vercel 프로젝트의 Settings → Environment Variables에 이름 BOOTSTRAP_KEY로 키를 추가합니다.
  3. Deployments → ⋯ → Redeploy를 누르고 앱을 새로고침합니다.
새 버전으로 업데이트하고 싶어요

Fork로 배포했다면 GitHub에서 내 저장소를 열고 파일 목록 위의 Sync fork → Update branch를 누릅니다. Vercel이 자동으로 다시 배포합니다.

Vercel 배포 시작으로 배포했다면 내 저장소가 Fork가 아닌 복사본이라 이 버튼이 없습니다. README의 새 버전 받기 명령으로 가져옵니다.

배포가 끝나면 아래 “예전 화면이 보여요” 안내대로 앱을 닫았다 엽니다.

새 버전을 배포했는데 예전 화면이 보여요

moyami는 설치형 앱이라 화면 파일을 기기에 보관하고, 앱의 탭과 창을 모두 닫았다가 다시 열 때 새 버전으로 바꿉니다. 새로고침만으로는 바뀌지 않습니다. 휴대폰은 최근 앱 목록에서도 닫아 주세요.

그래도 안 되면 사이트 데이터를 지웁니다. 이 기기에만 있던 설정은 사라지지만, 동기화된 읽기 기록은 다시 로그인하면 돌아옵니다.

  • PC Chrome·Edge — F12 → Application → Storage → Clear site data → 새로고침
  • Android Chrome — 설정 → 사이트 설정 → 모든 사이트 → 내 앱 주소 → 삭제
  • iPhone·iPad — 설정 → Safari → 고급 → 웹사이트 데이터 → 내 앱 주소 → 삭제. 홈 화면 앱은 지우고 다시 추가
예전 접근 키 방식에서 옮겨 왔어요

예전 moya-source-lite를 쓰던 Vercel 프로젝트에 그대로 moyami를 배포할 수 있습니다. 주소와 Upstash 연결은 그대로 씁니다.

  1. Environment Variables에 BOOTSTRAP_KEY와 SITE_NAME을 추가합니다.
  2. APP_ACCESS_KEY는 지워도 됩니다. APP_SECRET은 로그인에 계속 쓰이므로 그대로 둡니다.
  3. 다시 배포하고, 각 기기에서 위의 “예전 화면이 보여요” 방법으로 정리합니다.
  4. 관리자 계정을 만들고 저장소를 다시 추가합니다. 예전 기록은 새 계정으로 옮겨지지 않습니다.
앱 이름이나 주소를 바꾸고 싶어요

앱 이름은 SITE_NAME을 바꾸고 다시 배포하면 됩니다. 개인 도메인은 Vercel Settings → Domains에서 연결합니다. 브라우저 연결 확장을 쓴다면 APP_URL=https://내-도메인도 추가해 다시 배포하고 확장을 다시 설치하세요.

이 페이지에서 만든 키와 입력한 값은 페이지 밖으로 전송되지 않습니다.

자세한 설명은 moyami README를, 원본 리더는 Moya Reader를 참고하세요.
